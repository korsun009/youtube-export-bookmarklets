# Code review: YouTube Transcript & Subtitle Exporter v2 → v3

## Первопричины ошибок со скриншотов

1. `textarea.innerHTML = text` использовался для декодирования HTML-сущностей.
   На youtube.com действует Trusted Types, поэтому присваивание завершалось
   ошибкой `This document requires 'TrustedHTML' assignment`.
2. `overlay.innerHTML = ''` повторно вызывал ту же ошибку при переходе к экрану
   скачивания.
3. Каталог дорожек полагался на несколько жёстко записанных версий Android-
   клиентов. Эти версии и требования PO Token меняются независимо от скрипта.

## Исправлено

- Полностью исключены `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `eval` и
  системные `prompt`/`confirm`/`alert`.
- HTML-сущности, включая decimal и hex numeric entities, декодируются строковой
  функцией без DOM sink.
- XML, SRV3, JSON3, VTT и SRT разбираются отдельными проверяемыми парсерами.
- Открытая панель ищется в обычном DOM и открытых Shadow DOM с несколькими
  структурными и текстовыми fallback-путями.
- Добавена защита от повторного положения виртуализированной прокрутки, предел
  шагов/времени и обязательное восстановление исходной позиции.
- Активные запросы дорожек отменяются через AbortController.
- Реальный web player response текущей вкладки имеет первый приоритет.
- Версия текущего WEB-клиента берётся из ytcfg, а fallback-профили изолированы.
- Ошибки URL классифицируются: HTTP, пустой ответ, нераспознанный формат,
  ошибка парсинга и сеть.
- Неудача одной дорожки не отменяет другие и не удаляет готовые файлы.
- Добавлена единая GUI-оболочка выбора источников, форматов и нескольких дорожек.
- Финальный экран сохраняет все подготовленные файлы для повторного скачивания.
- Все результаты можно скачать одним ZIP-архивом без внешней библиотеки; кнопки
  отдельных файлов сохранены.

## Внешнее ограничение

По состоянию на август 2026 года YouTube применяет PO Token к части subtitle URL.
Токен может быть привязан к видео и требует attestation provider. v3 пробует URL,
которые уже доступны текущей странице и резервным клиентам, но не выдаёт обход
anti-abuse за гарантированное исправление. В этом случае пользователь получает
точную диагностику, а экспорт открытой DOM-расшифровки остаётся независимым путём.

## Проверки

Тесты покрывают Trusted Types-регрессию, сущности, XML/SRV3/JSON3/VTT/SRT,
таймкоды, длительности, объединение дорожек, сетевые fallback, HTTP 403, пустые
ответы, отмену, формирование четырёх типов файлов и структуру ZIP-архива.
