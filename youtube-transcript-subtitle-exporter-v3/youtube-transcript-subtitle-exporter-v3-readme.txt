YOUTUBE TRANSCRIPT & SUBTITLE EXPORTER v3.0
===========================================

Назначение
----------
Отдельный локальный bookmarklet для сохранения:
1) расшифровки из уже открытой панели YouTube;
2) одной, нескольких или всех найденных дорожек субтитров;
3) обоих источников за один запуск.

Дополнительный API key, MCP, сервер и ИИ-модель не используются.

Установка
---------
1. Откройте менеджер закладок: Ctrl+Shift+O.
2. Создайте или отредактируйте закладку.
3. Скопируйте всю строку youtube-transcript-subtitle-bookmarklet-v3.txt,
   начиная с javascript:, в поле URL закладки.
4. Откройте конкретное видео YouTube и нажмите закладку.

Графическая панель
------------------
Все параметры находятся в одном окне:
- расшифровка из открытой панели;
- дорожки субтитров;
- TXT с таймкодами;
- TXT без таймкодов;
- SRT;
- VTT.

Для дорожек нажмите «Найти дорожки», отметьте одну, несколько или все нужные
дорожки и затем нажмите «Подготовить файлы». Финальный экран позволяет скачать
каждый файл отдельно либо собрать все результаты в один ZIP одной кнопкой.

ZIP создаётся локально без CDN и внешних библиотек. Используется совместимый
режим STORE: архив объединяет файлы, но может почти не уменьшать их размер.

Расшифровка из панели
---------------------
Перед запуском вручную откройте под видео «Показать расшифровку» и дождитесь
строк. Скрипт не нажимает элементы YouTube, не открывает меню и не редактирует
страницу. Он прокручивает только найденный контейнер расшифровки, возвращает его
на прежнюю позицию и ограничен 1200 шагами и 90 секундами.

Поддерживаются обычный DOM, открытые Shadow DOM, transcript-segment элементы,
.segment-text, #segments-container, listitem и резервное чтение строк по
таймкодам. Дубликаты объединяются по времени и тексту.

Дорожки субтитров
-----------------
Сначала используется реальный player response текущей страницы. Затем скрипт
проверяет текущую web-конфигурацию YouTube, WEB_EMBEDDED и изолированный
ANDROID_VR fallback. Для URL проверяются исходный ответ, XML, JSON3, SRV3 и VTT.

Ошибка TrustedHTML со скриншотов исправлена: v3 нигде не присваивает innerHTML,
outerHTML и не вызывает insertAdjacentHTML. HTML-сущности декодируются чистой
строковой функцией.

PO Token
--------
YouTube может потребовать отдельный video-bound Proof of Origin Token именно для
скачивания субтитров. Такой токен создаётся для конкретного видео и сессии, а
его автоматическое получение требует отдельного attestation/token provider.
Этот bookmarklet не подключает внешний провайдер и не обходит защиту.

Если один URL отклонён, v3 автоматически пробует другие URL и профили. Если все
они отклонены, конкретная дорожка помечается предупреждением, остальные
продолжают обрабатываться, а уже подготовленные файлы не теряются.

Форматы
-------
TXT с таймкодами — удобен для чтения и анализа.
TXT без таймкодов — чистый текст.
SRT — стандарт для VLC, видеоредакторов и большинства проигрывателей.
VTT — WebVTT для HTML5-видео и совместимых программ.

Для дорожек используются длительности YouTube. Для строк DOM-панели, где виден
только старт, конец вычисляется по началу следующего фрагмента и ограничивается
длительностью видео.

Приватность и ограничения
-------------------------
- Текст обрабатывается локально; запросы идут только к YouTube.
- Если у видео нет субтитров, список дорожек будет пуст.
- Возрастные, региональные, закрытые и специальные видео могут не отдавать URL.
- Внутренние player API и DOM YouTube не являются стабильным публичным API.
- При остановке сохраняются уже подготовленные файлы.
