# Code review: YouTube Comments API Exporter v5.1 → v6

## Исправлено

- Цепочка `confirm` / `prompt` / `alert` заменена единым GUI с настройкой, прогрессом, остановкой, результатом и ошибками.
- Добавлена строгая проверка лимита: значения вроде `12abc`, `1.5` и отрицательные числа больше не принимаются частично через `parseInt`.
- Добавена защита от повторяющегося `nextPageToken` в `comments.list` для каждой ветки ответов. В v5.1 такая защита была только у `commentThreads.list`.
- Активный запрос и ожидание retry можно остановить через `AbortController`.
- Повторы 429/500/502/503/504 учитывают `Retry-After`.
- Частичный результат сохраняется и при остановке во время активного сетевого запроса.
- Сохранённый ключ удаляется автоматически только при однозначном `keyInvalid`; ошибка referrer или выключенный API не уничтожает потенциально рабочий ключ.
- Управление сохранённым ключом добавлено в основной интерфейс.
- Автоматическое скачивание заменено экраном результата с повторным скачиванием одного или всех файлов.
- TXT формируется из общей модели; добавлены Markdown, JSON и CSV.
- Финальный экран скачивает все выбранные форматы одним локально собранным ZIP;
  отдельное скачивание каждого файла сохранено.
- CSV защищён от formula injection при открытии в Excel.
- Во все форматы не попадает API key.
- Дубликаты, несовпадения ответов, повторные токены и число запросов остаются в диагностике.

## Сохранено из рабочего алгоритма v5.1

- Официальные `videos.list`, `commentThreads.list` и `comments.list`.
- `maxResults=100`, `textFormat=plainText`, режимы `time`/`relevance`.
- Догрузка ответов, которых нет во встроенном `thread.replies`.
- Два варианта трактовки пользовательского лимита.
- Нормализованный TXT с авторами, датами, лайками и прямыми ссылками.

## Осознанные ограничения

- YouTube Data API может не вернуть удалённые, удерживаемые или недоступные сообщения.
- Полный обход зависит от корректной пагинации внешнего API; v6 останавливает повтор токена и явно пишет это в диагностике.
- Ключ в localStorage защищён ограничениями API key, но доступен JavaScript того же origin и расширениям браузера. Пользователь может не сохранять его.

## Проверки

Автоматические тесты покрывают лимиты, ответы, дубликаты, повтор токенов, retry,
остановку, TXT/MD/JSON/CSV, ZIP, утечку ключа и запрет системных модальных окон.
