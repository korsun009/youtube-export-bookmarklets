YOUTUBE COMMENTS API EXPORTER v6.0
=================================

Назначение
----------
Локальный bookmarklet для выгрузки публичных комментариев и ответов через
официальный YouTube Data API v3. Страница YouTube используется только для
определения текущего Video ID; комментарии берутся из API, а не из видимого DOM.

Файлы
-----
youtube-comments-api-bookmarklet-v6.txt — готовая строка для URL закладки.
youtube-comments-api-exporter-v6.js — читаемый исходный код.
CODE-REVIEW.md — найденные проблемы v5.1 и выполненные изменения.

Установка
---------
1. Откройте менеджер закладок Яндекс Браузера: Ctrl+Shift+O.
2. Создайте закладку или отредактируйте прежнюю.
3. Название: например, «Экспорт комментариев YouTube v6».
4. Полностью скопируйте единственную строку из bookmarklet-файла, начиная с
   javascript:, и вставьте её в поле URL.
5. Откройте конкретное видео YouTube и нажмите эту закладку.

Настройки в графической панели
------------------------------
- API key YouTube Data API v3. Поле маскируется.
- Сохранение ключа в localStorage текущего браузера — по выбору.
- Удаление ранее сохранённого ключа прямо из панели.
- Ответы: включать или не включать.
- Порядок: time для максимально полного обхода или relevance для выборки.
- Любой целочисленный лимит; 0 означает без лимита.
- Лимит только по основным веткам либо по всем сообщениям вместе.
- Форматы: TXT, Markdown, JSON, CSV — один или несколько.

Остановка и ошибки
------------------
Кнопка «Остановить и сохранить найденное» отменяет активный запрос и формирует
частичный результат, если хотя бы одна ветка уже получена. Временные HTTP
429/500/502/503/504 повторяются до трёх раз; Retry-After учитывается.

Повтор nextPageToken отслеживается отдельно для страниц веток и для каждой
ветки ответов. Это исключает бесконечную пагинацию при сбое API.

Форматы
-------
TXT — человекочитаемый архив с диагностикой и ссылкой на каждое сообщение.
JSON — нормализованные метаданные, настройки без ключа, диагностика и ветки.
CSV — таблица с типом строки, parent_id, автором, датами, лайками, URL и текстом.
MD — структурированный Markdown для Obsidian, Notion, GitHub и баз знаний.
Опасные для Excel начальные символы формул нейтрализуются апострофом.

На финальном экране каждый файл можно скачать отдельно. Кнопка «Скачать всё ZIP»
создаёт один автономный ZIP-архив без CDN и сторонних библиотек.

API key и приватность
---------------------
Ключ не включается в TXT/MD/JSON/CSV и не выводится в интерфейс после ввода.
Если включено сохранение, ключ находится в localStorage origin youtube.com.
Для ключа рекомендуется ограничение по YouTube Data API v3 и HTTP referrer
https://www.youtube.com/* (при необходимости также https://youtube.com/*).

Скрипт обращается только к www.googleapis.com/youtube/v3 и работает с публичными
данными. OAuth, вход в Google-аккаунт, публикация и модерация не используются.

Квота
-----
videos.list, commentThreads.list и comments.list стоят по 1 единице за запрос.
Стандартная дневная квота проекта обычно равна 10 000 единиц. Панель показывает
фактическое число запросов и приблизительную долю этой квоты.

Ограничения
-----------
- Счётчик видео может меняться во время длительной выгрузки.
- Удалённые, удерживаемые или недоступные API комментарии могут дать расхождение.
- relevance не предназначен для доказательства полного обхода.
- При лимите диагностическое расхождение с общим счётчиком ожидаемо.
